Branch-Line / Tree Hand Calc

v1.0.3 · NFPA 13-2022 hydraulics

User Guide

  • Enter K, pressure at the most remote head, pipe size, length, C factor, and elevation change.
  • Q = K√P at the head. Friction uses Hazen-Williams. Elevation is 0.433 psi/ft.
  • Equivalent lengths for fittings should be confirmed for the edition and C factor.
  • Carry total flow and pressure to the next node or to the Junction Balancer.

Simple multi-head: equal K, equal spacing. Fitting equivalent lengths not yet included — add manually to length if needed.
