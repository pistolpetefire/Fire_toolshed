What you need to begin

The owner’s original PDF files or a ZIP of PDFs, a project name, and a jurisdiction. Quantities are not required to receive documents or begin hazard classification. Confirm the governing code, adopted edition and amendments before analysis. Selecting “Florida” does not select these automatically.

1. Upload the owner’s package

  1. Open Project and code basis. Enter the project, jurisdiction, selected assessment basis and code edition. Keep the owner’s original delivery separately.
  2. Under Receive the SDS package, give the delivery a useful name, such as “Building A — owner delivery — November 8.”
  3. Choose multiple PDFs, or choose a ZIP containing PDFs. A combined PDF containing several SDSs can be uploaded as one source. Files nested in ZIP folders are supported. Other file types appear in the receipt log and are not analyzed.
  4. Keep the tab open while reading runs. The progress line identifies the file and page. Use Pause after current page when necessary. To continue, reselect the original delivery; exact duplicate fingerprints prevent duplicate source records. A failed source also has a Retry PDF reading action in its review panel.
  5. Open Package receipts and excluded files and export the receipt log. Reconcile it with the owner’s delivery: every file should be registered, an exact duplicate, or explicitly excluded/rejected. An incomplete ZIP requires another upload of its remaining contents.

A filename is not a product identity. One PDF can contain several products; several PDFs can be revisions of one product. Therefore file count and material count may differ.

2. Confirm every document and product

Under Confirm documents and page ranges, select Review source and open the original PDF. Check the product name, manufacturer, product number and revision.

  • Single SDS: confirm that the proposed range covers the entire SDS. Use Review next 25 single-SDS suggestions to check straightforward documents together. Select only sources whose originals and identities you checked.
  • Combined PDF: add or adjust ranges for each SDS. Every page must be assigned once, in order. Mark cover sheets or unrelated pages Not an SDS and explain why. A guessed split is not accepted until you confirm it.
  • Scanned or poorly extracted pages: a Needs OCR flag requires attention. The workspace extracts existing text; it does not perform OCR. Obtain readable text using your OCR tool, compare it with the original, then paste and confirm corrected text in the source review panel. Check critical numbers, units and symbols.
  • Duplicate or revision: an identical file is retained as a receipt linked to the original. Different fingerprints remain separate. Possible matching products are flagged for review and are not silently merged. Keep aerosol and bulk formulations as distinct products when appropriate.

If an older assessment was restored, use the existing-material selector in source review to link its analysis to the appropriate page range. This preserves its permanent material identity.

3. Run the AI analysis in controlled batches

  1. In Analyze and review products, choose Select next 25 without results, or select specific materials. The interface permits no more than 50 materials per batch; 25 is a useful starting point for mixed-length SDSs.
  2. Choose Export selected AI batch. The ZIP contains the original PDFs, extracted text, confirmed page ranges, permanent IDs, project basis, and AI-INSTRUCTIONS.txt.
  3. Give that package and authorized governing code text to your organization’s approved AI environment. Follow the included instructions. The Tool Shed page itself does not run a hosted AI model or automatically send documents to an AI service. Your AI service may impose its own upload or context limits; reduce batch size when needed.
  4. Bring the returned JSON back through Preview AI results. Resolve identity, source-fingerprint or format errors, review the proposed changes, then apply the merge.
  5. Check Analysis batch reconciliation. Missing results remain pending. Importing one batch never marks the other materials complete. Review classifications, evidence, database corroboration and outstanding questions before issuing conclusions.
No quantities does not mean no hazards.

Product hazard classification can proceed from sufficient SDS and code evidence. Unknown inventory prevents complete quantity-dependent facility conclusions. This workflow does not calculate allowable MAQs, determine exceedances or occupancy, or establish facility compliance. The assessment workbook keeps those conclusions marked Not assessed.

4. Send the prefilled owner workbook

Select Download owner workbook. Product names, manufacturers, revisions, Material IDs and Inventory IDs are already filled in. Send this workbook to the owner to confirm site conditions, rather than asking them to recreate the SDS list.

Supported units include gal, L, mL, qt, pt, fl oz, lb, kg, g, oz and each. Volume is normalized to gallons; mass to pounds. Mass and volume are not converted into each other without density. Container counts alone are not equivalent to chemical contents. Use numeric values rather than spreadsheet formulas in quantity and container cells.

5. Preview the returned quantities before applying

  1. Choose Load returned Excel / CSV. Select the appropriate worksheet and map its column headings. The supplied workbook’s headings are recognized automatically.
  2. Build the import preview. Review matches, additions, updates, exclusions, unit conversions and unresolved information. Permanent IDs take precedence. An ambiguous name or similar product requires an explicit material selection; CAS alone does not establish a product match.
  3. Resolve every error. Warnings may be retained as unresolved questions; importing them does not establish that the assessment is complete. Confirm your review and apply the import.
  4. Check the inventory and import history. Existing records absent from the workbook are retained. To remove a material from active inventory, explicitly mark it No longer used or Duplicate, resolve its quantities and explain the change.
  5. Export assessment JSON or Excel. For detailed engineering review, import the assessment JSON into Assessment / HMIS. Exported location rows carry the linked product findings. Repeated hazard rows must not be summed as additional physical inventory.

The import updates located inventory while preserving product hazard findings. Reimporting an identical file is blocked; a later revised workbook produces a new recorded change.

Working with 1,500 materials

The workspace has no fixed material-count cap. Its practical limits are browser storage, device memory, PDF size, text quality and your AI environment’s limits. A 1,500-record automated regression checks inventory reconciliation; this is not a guarantee that every 1,500-PDF delivery will fit every device.

  1. Use one workspace per project. Keep a delivery register and upload manageable ZIP packages organized by building, department or owner delivery.
  2. Reconcile receipt counts after each package. Resolve failed files, missing page coverage and unreadable pages before considering the source package complete.
  3. Confirm straightforward sources in groups of 25; review combined and uncertain documents individually.
  4. Analyze product batches of 25–50. For 1,500 products this is approximately 30–60 batches. Track each batch’s missing results instead of relying on an AI response claiming it covered everything.
  5. Export the prefilled owner workbook for the full product register. If departments return separate files, import each one by permanent IDs and review the retained records.
  6. Reconcile unique source documents, confirmed products, AI results, owner-confirmed locations and unresolved items. Multiple locations legitimately increase inventory rows; duplicate receipts do not create extra products.

Current guardrails: 100 MiB per PDF and 1 GiB of expanded PDF data per ZIP. Split larger files or archives before uploading. A single complete backup is limited to 500 MiB of stored PDFs to avoid excessive browser memory use.

Back up and recover your work

This version saves one active workspace in this browser on this device. It is not shared team storage. Clearing site data, private browsing or changing browsers can lose access to local records. Work in one tab and make a backup after each major milestone.

  • Complete backup ZIP: includes the workspace, original PDFs and extracted/corrected text. Use Restore workspace / assessment to reopen it. Missing originals prevent a backup being labelled complete.
  • Workspace JSON: includes records, analysis, inventory and audit history, but not PDF binaries or extracted page text. Keep original deliveries and exported AI batch ZIPs alongside it.
  • Large projects: retain original owner packages plus workspace JSON and smaller AI batch ZIPs with their originals. For recovery, restore workspace JSON, reattach the original owner packages to reconnect PDFs by fingerprint, then redo missing text corrections if needed.
  • Switch projects: export a complete backup first, then restore the other project’s workspace. Restore asks before replacing the active records.

If something is missing

Failed PDF: open source review, retry reading, or obtain an unlocked/readable replacement. Source count differs from material count: check combined PDFs, non-SDS ranges and revisions. AI batch cannot export: reattach missing original PDFs. Quantity import fails: inspect the row’s IDs, units, formulas, duplicate location keys and exclusion conflicts. Another tab changed the workspace: save a JSON copy of your current view and reload before continuing. Save failed: export available records immediately, preserve original deliveries and free browser storage before proceeding.

Completion check

Account for all delivered files and pages; confirm product identities; obtain a result or explicit unresolved question for every product; reconcile every owner inventory row; review all remaining questions and engineering conclusions. A successful upload alone is not a completed hazardous materials assessment.
