Before you start

You need the owner’s SDS PDFs (or a ZIP), a project name, and the jurisdiction. You do not need quantities yet. Set the code basis and edition before you export any AI batch.

1. Upload the SDS package

  1. Open Project and code basis. Enter the project name, jurisdiction, assessment basis, and code edition.
  2. Under Receive the SDS package, give the delivery a clear name (example: “Building A — owner delivery — November 8”).
  3. Choose the PDFs or a ZIP of PDFs. Combined PDFs that contain several SDSs are allowed. Other file types are logged but not analyzed.
  4. Keep the tab open while files are read. Use Pause after current page if needed. Reselect the same delivery later; exact duplicates are skipped automatically.
  5. Export the receipt log and confirm every file was registered, marked duplicate, or explicitly excluded.

A filename is not the product name. One PDF can hold several products. Several PDFs can be revisions of the same product. File count and material count may differ.

2. Confirm products and page ranges

Select Review source and open the original PDF. Confirm the product name, manufacturer, product number, and revision.

  • Single SDS: accept the suggested range if it covers the whole sheet. Use Review next 25 single-SDS suggestions for straightforward files.
  • Combined PDF: set a range for each SDS. Every page must be assigned once. Mark cover sheets or non-SDS pages as Not an SDS and add a short reason.
  • Unreadable pages: the app extracts existing text but does not run OCR. Get readable text from your OCR tool, check it against the original, then paste and confirm it in the source panel.
  • Duplicates or revisions: identical files stay linked to the original. Different files stay separate. Matching products are flagged for you to review; they are not merged automatically.

If you restored an older assessment, use the existing-material selector in source review to link it to the correct page range. This keeps the permanent material ID.

3. Classify hazards in batches of 25

  1. In Analyze and review products, click Select next 25 without results (or select specific materials). Maximum is 50; 25 is recommended.
  2. Click Export selected AI batch. The ZIP contains the PDFs, extracted text, permanent IDs, project basis, and AI-INSTRUCTIONS.txt.
  3. Give the ZIP to your AI. Follow the instructions inside. This page does not run AI or send files for you.
  4. Bring the returned JSON back with Preview AI results. Fix any errors, review the changes, and apply the merge.
  5. Check Analysis batch reconciliation. Missing results stay pending. One batch does not mark other materials complete.
Hazards can be classified before quantities are known.

Unknown quantities stop you from finishing MAQ and occupancy conclusions. The app flags items for review; you make the final determination.

4. Collect quantities with the owner workbook

Click Download owner workbook. Product names, manufacturers, Material IDs, and Inventory IDs are already filled in. Send the workbook to the owner instead of asking them to rebuild the list.

Owner fillsWhat to do
Material ID / Inventory IDKeep the prefilled IDs. For another location, copy the row, keep the Material ID, and clear Inventory ID so a new record is created.
On siteYes, No longer used, Duplicate, or Unknown. Explain Duplicate in Notes.
Building, room, control area, processOne row per material and location. Use the real site names. Do not guess control-area boundaries.
Storage / closed-use / open-useEnter plain numbers and a unit. Leave unknowns blank. Enter 0 only when the amount is confirmed zero.
Owner totalOptional confirmed total. The app does not add storage and use quantities together (they can overlap).
Confirmed by / date / NotesWho confirmed the data, the date, and any assumptions.

Supported units: gal, L, mL, qt, pt, fl oz, lb, kg, g, oz, each. Volume becomes gallons; mass becomes pounds. Do not use formulas in quantity cells.

5. Import the returned quantities

  1. Click Load returned Excel / CSV. Select the sheet and confirm the column headings (the supplied workbook is recognized automatically).
  2. Build the import preview. Check matches, additions, updates, and unresolved items. Permanent IDs take priority. Ambiguous names need a manual material selection.
  3. Fix every error. Review warnings, then apply the import.
  4. Check inventory and import history. Records missing from the workbook are kept. To remove a material from active inventory, mark it No longer used or Duplicate and explain why.
  5. Export assessment JSON or Excel. Import the JSON into Assessment / HMIS for detailed review. Do not sum repeated hazard rows as extra inventory.

Large projects (up to 1,500 materials)

There is no fixed material-count limit. Practical limits are browser storage, device memory, PDF quality, and your AI’s batch size.

  1. Use one workspace per project. Upload manageable ZIP packages by building or delivery.
  2. Reconcile the receipt log after each package. Fix failed files and missing page coverage before moving on.
  3. Confirm simple sources in groups of 25. Review combined or uncertain documents one by one.
  4. Run AI batches of 25–50. For 1,500 products that is roughly 30–60 batches. Track missing results; do not assume one response covered everything.
  5. Export the owner workbook for the full register. Import department files one by one by permanent ID.
  6. Reconcile unique sources, confirmed products, AI results, owner locations, and open questions before calling the work complete.

Limits: 100 MB per PDF, 1 GB expanded per ZIP. A complete backup is limited to 500 MB of stored PDFs. Split larger deliveries.

Back up and recover

The workspace is saved in this browser on this device. It is not shared team storage. Clearing site data or changing browsers can lose the records. Work in one tab and back up after each major step.

  • Complete backup ZIP: includes the workspace, original PDFs, and extracted text. Use Restore workspace / assessment to reopen it.
  • Workspace JSON: includes records, analysis, and inventory, but not the PDF files. Keep the original deliveries and AI batch ZIPs with it.
  • Large projects: keep original packages plus workspace JSON and the AI batch ZIPs. To recover, restore the JSON, reattach the original packages (fingerprints reconnect them), then redo any missing text corrections.
  • Switch projects: export a complete backup first, then restore the other project.

If something is missing

Failed PDF: retry reading in source review or replace the file. Source count differs from material count: check combined PDFs and non-SDS ranges. AI batch will not export: reattach missing original PDFs. Quantity import fails: check IDs, units, formulas, and duplicate locations. Another tab changed the workspace: export a JSON copy and reload. Save failed: export what you can, keep the original PDFs, and free browser storage.

Done when

Every delivered file and page is accounted for, every product identity is confirmed, every product has results or an open question, every owner inventory row is reconciled, and you have reviewed the remaining questions and engineering conclusions. A successful upload alone is not a completed assessment.
