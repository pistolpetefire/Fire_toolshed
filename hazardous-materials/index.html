Classify materials by the selected code basis, confirm their uses, and export an Excel hazard register for review.

1. Set the basis and load the package

Select SDS PDFs in a batch. This records their identities; give the actual PDFs and exported JSON to your AI along with the applicable code text. Import its completed JSON here for validation. This page does not run a hosted AI model.

2. Review materials and resolve missing information

SDS hazard labels are evidence, not automatic IBC or NFPA classifications. Record each applicable code hazard separately. Storage, closed-system use and open-system use are maximum expected quantities; leave unknown values blank. Enter zero only when confirmed absent. Exported files retain unresolved items. Every hazard requires online database corroboration with a matching identity, source URL, access date and evidence before validation. This is a starting inventory for future HMMP development, not a completed HMMP.

Database references: NIH PubChem · NIOSH Pocket Guide · NOAA CAMEO Chemicals. AI must open and inspect relevant records; a search result alone does not confirm a hazard.
