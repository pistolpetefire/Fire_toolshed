Available callable utilities

Additional checks: pressure balance, water storage, occupant load using supplied factors, battery capacity and lumped-load voltage drop. Design criteria remain explicit inputs.

Hydraulic arithmetic: water velocity, sprinkler discharge and Hazen-Williams pipe friction. Each returns inputs, units, method and limitations. Download hydraulic functions (required beside tools.mjs and run.mjs).

PDF scale metadata reader (Python) reads standard viewport scales locally in the AI file environment. Requires pypdf. Unsupported formats are flagged.

  • Scale-checked route measurement: measures a supplied polyline inside one viewport after checking scale against a labeled dimension.
  • Cross-document value comparison: flags differences between provenance-tagged values in matching units.
  • Review coverage: identifies missing checks and unresolved determinations.
