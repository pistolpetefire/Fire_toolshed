## Bulk SDS Workspace Walkthrough

Place the walkthrough video here as:

`Tool_Shed_Bulk_SDS_Walkthrough_Balanced.mp4`

The page at `index.html` embeds it with:

```html
<source src="./Tool_Shed_Bulk_SDS_Walkthrough_Balanced.mp4" type="video/mp4">
```

Once the MP4 is in this folder, the video player on https://pistolpetefire.github.io/Fire_toolshed/video-training/ will work.

The file is ~21 MB. Upload it via the GitHub web UI (drag-and-drop into this folder) or `git` / Git LFS if preferred.
