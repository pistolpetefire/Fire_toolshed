Bulk SDS Workspace Walkthrough

Practical tour of the owner SDS package workflow: receive documents, review products, AI handoff, and quantity confirmation. Companion to the Bulk SDS user guide.

Duration ~10 minutes · Training examples only · No engineering conclusions issued

Full walkthrough Open bulk workspace User guide Assessment / HMIS

What the walkthrough covers

  • Project and code basis setup
  • Receiving the SDS package (PDFs or ZIP), receipt log, and duplicate handling
  • Confirming documents and page ranges (including combined PDFs)
  • Readability checks and extracted text review
  • Selecting controlled analysis batches (25–50 products) for your AI environment
  • Previewing and merging returned analysis results (missing records stay pending)
  • Downloading the prefilled owner workbook and mapping returned inventory columns
  • Reviewing quantity conversions, unknowns, and applying the import
  • Import history, backups, and recovery guardrails
  • Scaling notes for large inventories (~1,500 materials)

Upload is only the first step. Account for every file and page, confirm product identities, reconcile analysis results, obtain owner inventory facts, and review remaining questions before drawing facility conclusions.

Using the training videos

Open the corresponding tool alongside the video. The Bulk SDS workspace stores one active workspace in your browser on this device — it is not shared team storage. Download a complete backup after important milestones.

The companion guides linked from each tool provide the written sequence and field definitions.
