Units

All calculations run in US units internally (1 in. = 25.4 mm, 1 ft = 0.3048 m, 1 gpm = 3.785411784 L/min = 0.2271247 m³/h, 1 psi = 6.894757 kPa = 0.06894757 bar). Switching units converts every value shown; nothing is rounded in storage.

Code basis

Flow test (NFPA 291)

Elevations default to 0 (level). Elevation head is 0.433 psi per ft.

A flow test whose pressure drop is under the warning threshold gives an unreliable extrapolation. This tool defaults to 10% (its spec); the Flow Test Report app uses 25%. Enter 25 to match it, or leave the default of 10.

Hydrant arms (laterals)

Each hydrant has its own arm. Size defaults to 6 in. (NFPA 24 minimum) and length is optional (blank or 0 means no arm friction is added). An arm left at the default size, or with no length, is marked "assumed, confirm" in the printout. Arm friction and arm velocity go into each hydrant's residual check.

How this tool works

  1. Enter the flow test (static, residual, flow). The tool prints the NFPA 291 available flow at the minimum residual and builds the supply curve.
  2. Enter the required fire flow and the hydrants flowing, or use the table lookup and hydrant suggestion for the chosen code basis.
  3. Enter the loop length, connections, pipe and the arm of each hydrant. The tool checks 6, 8, 10, 12 and 16 in. pipe for velocity, residual pressure at every hydrant (arm friction included), a single-break case and the pressure class.
  4. Items marked "confirm with AHJ/edition" were not verified in the code text. They are listed on the report.
