# Hydrant Loop Sizer

Sizes a private hydrant loop that is fed by hydrants only (no tank, no pump) from one hydrant flow test. Version 1.0.2. Static site, no build.

## What it does
- NFPA 291 available flow at 20 psi: Q_R = Q_F x ((Ps - Pmin) / (Ps - Pr))^0.54. The supply curve used inside the loop is P(Q) = Ps - (Ps - Pr)(Q/Qf)^1.85.
- Ring hydraulics for 6, 8, 10, 12 and 16 in. mains (DN150, 200, 250, 300, 400 labels): Hazen-Williams, p = 4.52 Q^1.85 / (C^1.85 d^4.87) psi/ft with the actual inside diameter, v = 0.4085 Q / d^2, elevation 0.433 psi/ft.
- One or two connections, hydrants placed far or evenly, single-break case (50%, 100% or not checked), hydrant arms (default 6 in., optional length and size) whose friction and velocity go into each hydrant's residual.
- Code bases: Florida (FFPC 8th / 9th), IBC/IFC, DoD (UFC 3-600-01, UFC 3-230-01). Items flagged U show "confirm with AHJ/edition".
- A loop schematic (screen and printout) with pipe size, length and flow per segment; US customary or metric units (m, L/min or m3/h, kPa or bar); the ductile-iron nominal-to-ID table with the DN vs US nominal note.
- Report logo: the shared module `shared/report-logo.js`, storage key `fireToolshed.reportLogo.v1`, same options as Flow Test Report and Fire Pump Sizer (Benham, MeadHunt JV, AI&P + Benham, Haskell by state, upload).
- Missing inputs are asked for before printing; nothing is defaulted silently.

## Modeling notes
- Both connections are modeled as equal-head sources on one combined test curve evaluated at the total flow. Surge, fittings and hydrant losses default to 0.
- "Far" placement follows the spec convention: an open path of length L / sources carrying the break flow. It is conservative; the real loop topology is shorter.
- IDs in the DI table are computed (OD - 2 x wall - 2 x lining). Confirm with the pipe maker. "Custom" lets you enter nominal or manufacturer IDs.
