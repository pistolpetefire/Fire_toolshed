# Hydrant Loop Sizer

Sizes a private hydrant loop from one hydrant flow test, or checks a fire pump and tank that feeds the same loop. Version 1.1.0. Static site, no build. This app has no service worker; cache-busting is the `?v=1.1.0` tags on its stylesheet and scripts.

## What it does
- NFPA 291 available flow at 20 psi: Q_R = Q_F x ((Ps - Pmin) / (Ps - Pr))^0.54. The supply curve used inside the loop is P(Q) = Ps - (Ps - Pr)(Q/Qf)^1.85.
- Ring hydraulics for 6, 8, 10, 12 and 16 in. mains (DN150, 200, 250, 300, 400 labels): Hazen-Williams, p = 4.52 Q^1.85 / (C^1.85 d^4.87) psi/ft with the actual inside diameter, v = 0.4085 Q / d^2, elevation 0.433 psi/ft.
- One or two connections, hydrants placed far or evenly, single-break case (50%, 100% or not checked), hydrant arms (default 6 in., optional length and size) whose friction and velocity go into each hydrant's residual.
- Code bases: Florida (FFPC 8th / 9th), IBC/IFC, DoD (UFC 3-600-01, UFC 3-230-01). Items flagged U show "confirm with AHJ/edition".
- A loop schematic (screen and printout) with pipe size, length and flow per segment; US customary or metric units (m, L/min or m3/h, kPa or bar); the ductile-iron nominal-to-ID table with the DN vs US nominal note.
- Report logo: the shared module `shared/report-logo.js`, storage key `fireToolshed.reportLogo.v1`, same options as Flow Test Report and Fire Pump Sizer (Benham, MeadHunt JV, AI&P + Benham, Haskell by state, upload). The AI&P option is added by the shared module when the page's own list does not already contain it.
- Missing inputs are asked for before printing; nothing is defaulted silently.
- Pump and tank mode (NFPA 24 2019 or 2022, same Hazen-Williams formula either way; NFPA 20 s6.2 for the curve limits; NFPA 1 Chapter 18 for the hydrant fire-flow context). The source is the pump curve, not a flow test. Inputs are rated flow and pressure, churn (not over 140% of rated pressure), pressure at 150% of rated flow (not under 65% of rated pressure), and tank low-water suction. A supply main runs from the pump to the loop. Each sprinkler riser has a lead-in and a backflow-preventer loss, because the hydrants share the loop. The report shows normal operation and one loop segment out: required pump discharge, pressure available at the demand, PASS or FAIL, and the margin.

## Pump curve and the sample check
Net pressure is a straight line between the three entered points: churn at 0 gpm, the rated point, and 150% of rated flow. It is not extended past 150%. Available discharge is that net pressure plus the tank low-water suction. The sample enters churn and the 150% point at the NFPA 20 limits (140% and 65% of 115 psi), so at 2,602 gpm the line from 2,500 gpm / 115 psi to 3,750 gpm / 74.75 psi is 111.7 psi. Suction is 0, so available discharge is 111.7 psi.

Friction uses the ductile-iron actual inside diameters already in this tool (12 in. = 12.52 in., 10 in. = 10.46 in.), C = 140, and p = 4.52 Q^1.85 / (C^1.85 d^4.87). With the demand at the far point, the intact loop splits equally (1,301 gpm each way over 1,160.5 ft). The governing break is the same open path this tool already uses for a far-point hydrant break: the full 2,321 ft carries 2,602 gpm. Closing only one of the two half-loops is also shown and does not govern.

Those actual-ID results are supply main 1.64 psi at 6.78 ft/s, intact loop 1.46 psi, full-loop break 10.56 psi, lead-in 1.64 psi, required discharge 111.14 psi normal and 120.23 psi with the loop broken. Normal operation passes (margin 0.58 psi). The loop break fails (short 8.51 psi). The screen rounds pressure to one decimal (111.1 psi, 120.2 psi, margin 0.6 psi, short 8.5 psi). A nominal-ID check (12.00 in. and 10.00 in.) is closer to the 2.0 psi and 1.8 psi figures and gives 7.38 ft/s, not 6.8 ft/s, and it would fail the normal case as well. The 6.8 ft/s figure matches the 12.52 in. inside diameter. The 1.4 psi lead-in does not match either the 10.46 in. actual ID (1.64 psi) or the 10.00 in. nominal ID (2.04 psi). This tool does not adjust the formula or the diameters to force those figures. See the 1.1.0 changelog.

## Modeling notes
- Both connections are modeled as equal-head sources on one combined test curve evaluated at the total flow. Surge, fittings and hydrant losses default to 0.
- "Far" placement follows the spec convention: an open path of length L / sources carrying the break flow. It is conservative; the real loop topology is shorter.
- IDs in the DI table are computed (OD - 2 x wall - 2 x lining). Confirm with the pipe maker. "Custom" lets you enter nominal or manufacturer IDs.
