Help & limits

Purpose: Preliminary screen of closed-door leakage and corridor smoke under well-mixed assumptions.

Orifice equation: Q = Cd · A · √(2|ΔP|/ρ) · sign(ΔP). Mass flow = ρ · |Q|.

Inferred area: From measured flow and test pressure: A = Q / (Cd · √(2|ΔP|/ρ)).

Buoyancy (optional): Simplified ΔP_buoy ≈ ρ · g · h · (ΔT/T). User states reference height.

Smoke balance: Explicit well-mixed corridor soot mass balance with inflow, outflow, and replacement air. Visibility from user-entered extinction coefficient.

Do not invent code sections, leakage values, soot yields, or criteria. Identify all sources.

Limits: No CFD, stratification, or automatic tenability. Reverse pressure reverses modeled flow only.
