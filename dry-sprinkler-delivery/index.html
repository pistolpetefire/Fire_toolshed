Methodology & assumptions

  • Eligible systems only: dry pipe and double-interlock preaction. Wet pipe is rejected for water delivery compliance (water is already at the heads). Single-interlock is not evaluated here.
  • Tree / simple branched networks only (no full grids in v1).
  • Volume: π/4 · (ID/12)² · L · 7.4805 gal; optional fitting volume ≈ 15% of EL as pipe.
  • Hazen–Williams: p = 4.52 Q1.85 / (C1.85 d4.87) psi/ft; elev 0.433 psi/ft.
  • Trip: t ≈ 0.0352 · (VT/(An√T₀)) · ln(pa0/pa); QOD applies 50% planning reduction.
  • Transit: t = 60 · Vremote / Qfill; Qfill from residual @ DPV via inverse HW, or override.
  • Bands: Green ≤90% of limit; Yellow within 10% (still ≤ limit); Red exceeds.
  • Does not model compressible multi-phase flow, accelerator dynamics, or listed software methods.
  • Not a substitute for listed calculation programs or field trip testing.

    Project title printed on every report and used in download filenames. Appears in history labels. Required for clear archives; not used in the math.
    Building / area
    Site, building number, or remote area name (e.g. “Warehouse high bay – System 1”). Report metadata only.
    Engineer name
    Preparer’s name for the signature block and report header. Also used as the printed “Prepared by” field.
    PE number (optional)
    Professional engineer license number if your firm puts it on charette packages. Optional; blank is fine for internal use.
    Company
    Firm name on the report header and signature block.
    Date
    Report date (defaults to today). Used on print/export and history labels.
    Building / occupancy description
    Free-text occupancy narrative (e.g. “OH-2 manufacturing, dry pipe, FM DS 8-9”). Helps AHJ packages; does not change the hazard table by itself—you still select Hazard below.
    Notes
    AHJ direction, QOD listing number, trip-test plan, or assumptions. Printed on reports under Notes.
    Report logo
    Logo for printed/saved reports. Options: Benham, MeadHunt JV, Haskell (by state), or upload an image. Selection is shared with other Fire Toolshed report tools in this browser.

    4. Criteria & hazard — each input

    System type
    • Dry pipe — eligible for NFPA 13 §8.2 water delivery time evaluation.
    • Double-interlock preaction — treated like dry for delivery time (both detection and sprinkler operation required before water).
    • Single-interlock preaction — rejected for delivery compliance in this tool (not evaluated under the dry table here).
    • Wet pipe — rejected. Water is already at the heads; dry delivery time does not apply. You may still model pipes for volume/HW information only.
    Criteria set — NFPA 13
    Compares estimated delivery time to the hard-coded NFPA water delivery table for the selected hazard. Exemptions (≤500 gal; ≤750 gal + QOD) apply.
    Criteria set — FM Global
    Uses the same numerical time limits as NFPA by default. Enter a stricter value in FM max delivery override if the governing FM data sheet requires it.
    Criteria set — Both (show stricter)
    Shows NFPA and FM side-by-side. Overall pass requires meeting the stricter (smaller) time limit. Both bands are reported.
    Hazard classification
    Selects the NFPA 13 water delivery row (max seconds and suggested number of open heads):
    HazardHeadsMax (s)
    Dwelling Unit115
    Light160
    Ordinary (Group 1 or 2)250
    Extra (Group 1 or 2)445
    High-Piled440
    Changing hazard auto-fills “Most remote sprinklers open”; you may still edit heads.
    Most remote sprinklers open
    Number of most remote heads assumed open for design flow and orifice area (1, 2, or 4). Used in K-factor mode as n in Q = n·K·√P, and for total open orifice area An in trip time. Must match the hazard table unless the AHJ allows a different assumption—document overrides in Notes.
    Quick-opening device (QOD) present
    Check if a listed accelerator/exhauster is provided. Effects: (1) enables ≤750 gal volume exemption when volume is 500–750 gal; (2) applies a 50% planning reduction to calculated trip time (unless you override trip time). Confirm listing and installation with the manufacturer and AHJ.
    FM max delivery override (sec)
    Optional. Blank = use the same max seconds as the NFPA hazard row. Enter a smaller number when FM Global or the occupancy-specific data sheet is stricter. Does not change the NFPA column when Both is selected—it only tightens the FM limit.
    Units — US Customary
    Default. All calculations run in gal, ft, psi, gpm. Displays match the engine.
    Units — Metric display
    Converts live displays to L, m, kPa, L/min. The calculation engine remains US customary; this is display-only conversion for readability.

    5. Design flow & hydraulics — each input

    Design mode — K-factor × √P × heads
    Design flow Q = n · K · √Pmin, where n = open heads, K = sprinkler K-factor, Pmin = minimum residual pressure at the remote heads. Use when you size from listed K and required residual (common for remote-area checks).
    Design mode — Total design flow
    You enter the total gpm for the open remote heads (or a planning total). Use when a hydraulic package or hand calc already provides demand at the remote.
    Design mode — Density × area
    Q = density (gpm/sf) × design area (sf). Useful for preliminary density-area demand; may overstate flow vs only the open remote heads—use carefully for delivery estimates.
    Sprinkler K-factor
    Listed K of the open remote sprinklers (e.g. 5.6, 8.0, 11.2, 25.2). Used for design Q in K-mode and to estimate orifice area An for trip time. Use the same K for all open heads in this simplified model.
    Min. pressure at remote (psi)
    Required residual pressure at the most remote open heads (often 7 psi minimum for standard sprinklers; ESFR/storage listings may require much higher, e.g. 60 psi). This is the starting pressure for the HW walk back to the supply. Flag if your supply residual cannot support it.
    Total design flow (gpm)
    Visible in total-flow mode. Total gpm of water discharging at the open remote sprinklers for the hydraulic walk and as fallback fill rate.
    Design density (gpm/sf)
    Visible in density mode. Design density for the remote area (e.g. 0.15 for OH-1 planning). Confirm adopted code/edition.
    Design area (sf)
    Visible in density mode. Design area of application for the density-area calculation. Dry systems often use a larger design area than wet (+30% in many NFPA cases)—enter the area you are using for demand.
    Residual pressure at supply / DPV after trip (psi)
    Gauge residual available at the dry-pipe valve (or modeled supply node) once the valve has tripped and water is flowing.
    • Used to check whether available pressure ≥ required pressure from the remote HW walk.
    • Used to derive average fill rate for transit: Qfill from inverse Hazen–Williams after elev and fixed losses.
    • Enter a realistic residual from a flow test or pump curve at the expected fill/design flow—not the static only.

    6. Water delivery time inputs — each field

    Initial air pressure (psig)
    Supervisory air (or nitrogen) pressure on the dry system before trip. Converted to absolute (psig + 14.7) as pa0 in the trip formula. Typical dry systems often ~30–50 psig; use project set-point.
    Trip pressure (psig)
    Air pressure at which the dry-pipe valve is designed/set to trip (differential trip pressure), as gauge. Converted to absolute pa. Must be less than initial air pressure. Check valve data sheet.
    Temperature (°F)
    Air temperature used for absolute temperature T₀ = °F + 460 (°R) in the trip formula. Default 70 °F. Extreme cold/hot spaces can be entered if justified.
    Trip time override (sec)
    Optional. Blank = calculate trip with the FMRC-style formula (and QOD reduction if checked). Enter a value to force trip time (e.g. from a listed model or field test). Overrides all trip math.
    Transit method — Volume / flow
    Default. ttransit = 60 × Vremote (gal) / Qfill (gpm). Transparent volume-fill estimate for the path from DPV to most remote node.
    Transit method — Length / fill velocity
    ttransit = Lpath (ft) / vfill (fps). Use when you prefer a constant fill velocity assumption instead of volume/flow.
    Fill flow override (gpm)
    Optional. Blank = derive Qfill from residual @ DPV via inverse HW (preferred). If residual is missing or unusable, falls back to design Q of open heads. Enter a known fill rate from a model or test to override derivation.
    Mean fill velocity (fps)
    Visible when length/velocity transit is selected. Planning default 10 fps. Higher velocity shortens transit; document the basis.
    Transit time override (sec)
    Optional. Blank = calculate transit. Enter a value to force transit time from another analysis or test. Overrides volume/flow and L/v methods.
    ttrip ≈ 0.0352 × (VT / (An √T₀)) × ln(pa0/pa)
    ttransit = 60 × Vremote / Qfill  or  L / vfill
    Total delivery = trip + transit

    7. Network nodes — each input

    Supply / dry-pipe valve node
    Exact node name used in the pipe table as the supply end of the path (typically “DPV”). Must match a From or To name in the network. Pathfinding starts here.
    Remote sprinkler node(s)
    Comma- or semicolon-separated names of remote sprinkler locations (e.g. Remote, Remote2). Must match table nodes. When several are listed, the tool uses the path with the largest volume to a remote for delivery volume and transit.
    Include approximate fitting volume
    When checked, adds a planning allowance for fitting internal volume ≈ 15% of each segment’s equivalent length treated as pipe. Uncheck for pure pipe-only volume (common when comparing to software that ignores fitting volume).

    8. Pipe network table — each column

    Model a tree or simple branch only (no full looped grid solver). Use Add Row / Insert Row / Duplicate Path; per-row ⧉ duplicates and ✕ deletes.

    From
    Upstream (or either end) node name for the segment. Names are case-sensitive matches for pathfinding—keep consistent (e.g. always “DPV”, not “Dpv”).
    To
    Other end node name. Together with From, defines connectivity for the undirected tree path from supply to remote.
    L (ft)
    Centerline pipe length in feet. Must be > 0. Used for volume and for friction length (plus equivalent length).
    Nom.
    Nominal pipe size ½″ through 12″. Selects default internal diameter from Sch 10/40 tables when ID is left blank.
    Sch
    Schedule 10 or 40 for standard steel ID tables. Schedule 10 has larger ID (less friction, more volume) than Sch 40 for the same nominal size.
    ID (in)
    Actual internal diameter (inches). Leave blank to auto-fill from Nom + Sch. Override for ductile iron, copper, CPVC, or listed special IDs from a multi-page PDF (e.g. 10.42, 10.58).
    C
    Hazen–Williams C-factor. Default 120 for new black steel. 100 is common for older or mildly tuberculated steel. Soft warning if outside 80–150. Higher C → less friction.
    Fittings (counts)
    Counts of 90° elbows, 45° elbows, tee run, tee branch, gate, butterfly, check, coupling, reducer. Each multiplies the NFPA-style equivalent length for that size and sums into EL. Use branch tee when flow turns through the branch; run tee when flow is straight through.
    EL ovrd
    Optional total equivalent length (ft) for fittings on this segment. Blank = auto sum from fitting counts. Enter a value from a listed calc printout to match that EL exactly.
    Elev (ft)
    Elevation change From → To in feet (positive = rise in that direction). Converted at 0.433 psi/ft. Correct sign matters for required pressure at the supply (remote higher than DPV increases required residual).
    Fix ΔP
    Fixed pressure loss (psi) for devices that are not modeled as pipe friction alone—riser checks, OS&Y, butterfly valves, etc., as listed on multi-page PDF device rows. Added to friction on the HW walk and subtracted from available head when deriving fill rate.
    Vol gal
    Read-only segment volume (pipe ± fittings). Running total appears in metrics.
    Notes
    Free text (PDF page number, “crossmain,” “branch line,” listing note). Imported fixtures may append [PDF p.#].

    9. Outputs & color bands (read-only)

    Compliance
    MEETS (green ≤90% of limit) · TIGHT (yellow, within 10% of limit) · EXCEEDS (red) · EXEMPT (volume) · REJECTED (wrong system type).
    Water delivery (s)
    Trip + transit. Compared to NFPA/FM limit for the hazard.
    Trip / Transit (s)
    Components of delivery; formulas shown in the delivery panel.
    Total volume / Vol. to remote
    Full network volume vs path volume supply→most remote (drives exemptions and transit).
    Design flow
    Q used for the HW walk (and fill fallback).
    NFPA / FM cards
    Side-by-side delivery vs each limit and band when that criteria set is active.
    Hydraulic results table
    Node-by-node Q, residual pressure, friction (incl. fixed ΔP), elevation, and segment labels along the walk remote→supply.
    Segment volumes table
    Per-segment ID, L, EL, pipe/fitting/total gallons.

    10. Volume exemptions (NFPA 13)

    • ≤ 500 gal total system — no water delivery time requirement (EXEMPT).
    • ≤ 750 gal + listed QOD — no water delivery time requirement (EXEMPT).
    • > 750 gal without QOD — soft warning; time criteria apply.

    11. Assumptions & limits

    • Tree / simple branch only — no full gridded peaking solver
    • Steady-state HW; simplified volume/flow transit
    • No detailed multi-phase air or accelerator dynamics
    • Pump is not a curve device — enter residual pressure manually
    • Not a substitute for listed software or field trip testing
