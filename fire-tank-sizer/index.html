Fire Tank Sizer — Help / Input Guide

Purpose: Preliminary fire water tank sizing from system/pump flow × duration, plus planning safety factors. Select a US-typical prefab steel size under site height/diameter limits, with a concrete pad plan. Not a sealed NFPA 22 design.

Main Sizer → · Civil Summary →

Path: Flow Test → Fire Flow Calculator → Sprinkler Estimator → Fire Pump Sizer → Tank Sizer. Import Fire Flow for large site volumes.

NFPA 1 required fire flow

  • Edition: 2021 cites §18.4.5.3 (reduction, floors, and the 2,000 gpm / 2 hour cap) and §18.4.5.4 (greater of fire flow and sprinkler demand). 2024 cites §18.4.4 for the same rules. The edition does not change the math, and this tool does not invent 2024 subsection numbers.
  • Construction and area: Lookup uses the toolshed area bands (the same bands as the Hydrant Loop Sizer). Type II (000) is the IIB group. Type V (000) is VB.
  • Sprinklered throughout: Flow = the smaller of 2,000 gpm and the larger of 25% of the table flow and the floor. The floor is 1,000 gpm, or 600 gpm when quick-response sprinklers are used throughout. Duration = the smaller of the table duration and 2 hours. The result is labeled AHJ may modify.
  • Table flow and duration overrides: Type the adopted table's numbers when you do not want the lookup. Leave them blank to use the lookup. Do not type a guessed code value.
  • Sprinkler demand: The supply rate is the greater gpm. The tank volume is the greater of the two volumes. The demands are not added.
  • Apply to tank demand writes that supply into the flow and duration used for the tank. It does not add the tank's safety percent until the demand section does.

Demand inputs

  • System / pump flow (GPM): The greater of sprinkler demand and fire flow when both are known. Not the sum.
  • Duration (min): Duration of the demand that needs more gallons. Imported with a capture when available.
  • Use Governing Demand: Compares a saved sprinkler capture and a saved fire-flow capture and keeps the greater rate and the greater volume.
  • Import Upstream Demand: Prefers that comparison, else Fire Pump Sizer capture, else Sprinkler Estimator.
  • Import Pump Demand: Loads Capture for Tank from Fire Pump Sizer.
  • Import Fire Flow: Loads the Fire Flow Calculator capture. The reduction is applied in that calculator, not a second time here.
  • Import Sprinkler: Loads Capture for Pump Sizer (flow + duration + project fields).

Safety framework scenarios

  • NFPA planning (+5% default): Base = Q×t; small contingency for freeboard/suction planning. Confirm NFPA 22 effective capacity.
  • UFC planning (+10%): Higher contingency for DoD-style projects; confirm UFC duration/redundancy.
  • FM Global planning (+15%): More conservative planning; cite governing FM DS.
  • Safety contingency override %: Blank = use framework default; enter a number to force a custom %.
  • Unusable %: Increases required shell volume so usable water still meets demand after freeboard/suction allowances.

Site constraints

  • Max tank height: Local zoning / AHJ / aircraft / aesthetic limit. Filters prefab catalog. 0 = no limit.
  • Max diameter: Site footprint / setbacks. Filters catalog. 0 = no limit.
  • Pad beyond shell: Concrete pad extends this far past tank diameter on each side (plan diameter = tank ⌀ + 2× beyond).
  • Pad thickness: Used only for approximate concrete volume (cu yd). Structural design by others.

Prefab catalog, field-erected screening, and custom

  • Prefab rows are planning nominals for bolted / reservoir / standpipe-style steel tanks. They are not a manufacturer's catalog. Confirm with the manufacturer.
  • Green/white rows meet volume + max H + max ⌀. Click to select.
  • Field-erected list: When no prefab row fits, the page lists practical diameters and heights for a field-erected welded steel tank. Nominal gallons are the calculated cylinder volume, rounded up to the next 1,000. The list is labeled AWWA D100 because that is the usual standard for this kind of tank. It is a screening list to confirm with the tank manufacturer, not a product catalog. A row may exceed the entered height or diameter; the status column says so.
  • Custom diameter & height: Override both lists with project geometry. Capacity is the cylinder volume.
  • Report logo: Benham, MeadHunt JV, AI&P + Benham (a Haskell Company), Haskell by state, or an uploaded image. The choice is shared across Toolshed report tools.

Outputs

  • Plan diagram: Tank + concrete pad with dimensions (pump-sizer style).
  • Clean Report: On-screen preview + print dialog.
  • Save Report: Downloads HTML report + JSON data files.
  • Save tank handoff: Stores selection for future tools / records in browser storage.

Scenarios

  • Height-limited site: Set max H low; catalog prefers wider, shorter tanks.
  • Tight footprint: Set max ⌀; taller options appear if height allows.
  • Long duration (UFC extra / FM): Import duration from sprinkler app; required shell grows with Q×t and safety %.
