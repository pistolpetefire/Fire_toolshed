Syllabus locker

User manual

Study Calc II by exam. Do the work on paper. Then open the solve path to check.

How to use it

  1. Open an exam unit (Exam 1, 2, 3, or Final).
  2. Drill that unit’s topics, or run a practice exam.
  3. Answer on paper first. After you pick a choice, read all five tutor blocks.
  4. Clear Review missed before the real test.
  5. When you have a syllabus, paste coverage into the Syllabus locker so key focus matches your section.

What each button does

  • Exam cards — topics + key focus for that test.
  • Topic practice — MCQs, one topic at a time.
  • Practice exam — mixed questions from one unit (or all 225 for the final).
  • Workshop — free-response. Hints → method → full solution → what to write / how to check.
  • Review missed — only items you got wrong, until you get them right.
  • Formula sheets — short strategy lists, not a substitute for working problems.
  • 16-week plan — check off weeks; saved on this device only.

After every MCQ

  1. Start here — first move.
  2. Method — how to solve any problem of that type.
  3. This problem — the actual steps.
  4. Why each choice — correct vs traps.
  5. Write-up + check — what to put on the exam, how to verify.

Practice which exam?

Tap a unit. Length uses the home-screen “Practice-exam length” box (max 75 per midterm, 225 on the final).

Typical OSU MATH 2153 coverage: techniques of integration (parts, trig, trig sub, partial fractions), improper integrals, arc length/surface/work, sequences, series tests, power & Taylor series, parametric equations, polar coordinates.

Usually later courses (not emphasized here): multivariable (Calc III), vector calculus, rigorous epsilon-N proofs, DE beyond a light separable mention.
