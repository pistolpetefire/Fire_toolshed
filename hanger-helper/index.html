Fire Toolshed

Hanger & Stocklist Helper

v1.0.0 · NFPA 13-2022 Ch. 17

User Guide

  • Enter pipe size, run length, and maximum hanger spacing.
  • The tool counts hangers, suggests rod size, and checks the 5W + 250 lb load.
  • Fitting take-off lengths are editable defaults — printed as “assumed, confirm”.
  • Spacing and rod sizes should be verified against a licensed copy of NFPA 13.
