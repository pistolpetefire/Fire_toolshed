# Batch 2 Verification tabs: independent Python hand calcs

Each older Engineering Tools app now has a **Verification** section (shared/verify-tab.js) and a per-app case file
(`<app>/assets/verify-cases.js`). The case files are generated by the Python scripts in this folder. Each script works the
cases from the cited equations or code tables. None of them calls the app's JavaScript.

```bash
cd validation/verify && for f in *.py; do [ "$f" = ftverify.py ] || python3 "$f"; done   # regenerate case files
node validation/test-verify-batch2.mjs http://localhost:8765                              # or the live Pages URL
```

How the check works: "Run checks" opens a hidden second copy of the page (`?ftverify=1`) that runs on memory-only storage, so
the user's saved inputs are never read or changed. The harness enters each case's inputs, reads the app's displayed
result (or, for apps with an exported engine, the engine's return value), and compares it with the Python value.
A numeric pass is within 1%; a code-table lookup must match exactly. The run record is for traceability only. It is not
a professional seal or certification.

## Fixed

  - **Diesel tank:** sized per NFPA 20 (2022) 11.4.1.3.1 and 11.4.1.3.1.1, at 12 h × the entered manufacturer rate + 10%, or 1 gal/hp + 10% when no rate is entered.
