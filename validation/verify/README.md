# Batch 2 Verification tabs: independent Python hand calcs

Each older Engineering Tools app now has a **Verification** section (shared/verify-tab.js) and a per-app case file
(`<app>/assets/verify-cases.js`). The case files are generated by the Python scripts in this folder. Each script works the
cases from the cited equations or code tables. None of them calls the app's JavaScript.

```bash
cd validation/verify && for f in *.py; do [ "$f" = ftverify.py ] || python3 "$f"; done   # regenerate case files
node validation/test-verify-batch2.mjs http://localhost:8765                              # or the live Pages URL
```

How the check works: "Run checks" opens a hidden second copy of the page (`?ftverify=1`) that runs on memory-only storage, so
the user's saved inputs are never read or changed. The harness enters each case's inputs, reads the app's displayed
result (or, for apps with an exported engine, the engine's return value), and compares it with the Python value.
A numeric pass is within 1%; a code-table lookup must match exactly. The run record is for traceability only. It is not
a professional seal or certification.

## Flagged items (app math differs from the cited source; flagged, not fixed)

| App | Item | Effect |
|---|---|---|
| Deflagration Vent | Dust and gas vent equations do not match NFPA 68 (dust: V^(2/3) Pred^(-1/2), no Pmax/Pred term; gas: exponents on wrong pressures) | Dust under-sized about 70%; gas over-sized 3 to 4 times in the test cases |
| Smoke Exhaust Lab | Plugholing Vmax uses a temperature rise from 0.5 Qc rather than the layer temperature | Vmax about 29% low (conservative) |

Review notes, not math errors: FA Power Extenders UFC standby duration not confirmed; Dry Sprinkler fill rate
ignores open-sprinkler loss (optimistic transit); Occupant Egress rounds occupant load to nearest; IBC/IFC explosives
Division 1.4 maps to H-3.

Not applicable (no calculations): Water Supply path hub, Flow Test Request form.

## Fixed

- **Fire Pump Sizer v2.4.0 (2026-10-14).** Three changes:
  - **Diesel tank:** sized per NFPA 20 (2022) 11.4.1.3.1 and 11.4.1.3.1.1, at 12 h × the entered manufacturer rate + 10%, or 1 gal/hp + 10% when no rate is entered.
  - **Minimum OCPD:** per NEC (2023) 695.4(B)(2)(a)(1), from the entered locked-rotor current plus the FLC of the other pump motors and accessories, then the next standard size in 240.6(A).
  - **Churn check:** checks the entered certified-curve shutoff against 140% of rated per NFPA 20 (2022) 6.2.2. With no shutoff entered, it shows as not checked, never as a pass.
  - The version is now read from the page.
  - Verification: 13 of 13 checks pass.

- **Occupant Egress v1.2.0 (2026-10-14).** IBC travel limits are now set by subgroup per IBC 2021 Table 1017.2:
  - F-1 / S-1: 250 / 200 ft. F-2 / S-2 / U: 400 / 300 ft (the U row was previously 300 / 200).
  - H-1 to H-5: 75 / 100 / 150 / 175 / 200 ft, sprinklered only.
  - I-1: 250 ft and I-2 / I-3: 200 ft, sprinklered only. I-4: 200 / 150 ft.
  - Opt-in IBC 1017.2.2 increase to 400 ft for F-1 / S-1.
  - IBC Table 1004.5 warehouses (500 gross) added; storage / stock / shipping stays at 300.
  - NFPA 101 (2018+) Table 7.3.1.2 business use is now 150 gross.
  - Saved v1.1.0 groups F / S / H / I migrate to the most restrictive subgroup (F-1 / S-1 / H-1 / I-2 / I-3).
  - Common path and dead-end values are unchanged (simplified group values). Per project and AHJ.

- **Dry Sprinkler Delivery v1.4.0-prelim (2026-10-14).** Two changes:
  - **Trip time:** V_T is now converted to ft³ and A_n to ft² before the SFPE/FM equation (it previously used gal and in², about 19 times short).
  - **Fitting equivalent lengths:** now per NFPA 13 (2025) Table 28.2.3.1.1, checked against the scanned 2025 text on law.resource.org. Blank table cells keep the app's planning values.
  - Delivery times were checked against NFPA 13 (2025) Table 8.2.4.3.2, and the 500/750 gal exemptions against 8.2.4.2.1/8.2.4.2.2; both unchanged.
  - The fill-rate method note (no loss through open sprinklers) still stands.

- **Concrete Fire Rating v1.1.0 (2026-10-14).** CMU expanded shale, clay or slate at 1 hr is now 2.6 in per IBC (2024) Table 722.3.2; it was 2.2 in, the 3/4 hr value.
  - All other wall, slab and CMU values were checked against the ICC Digital Codes 2024 IBC Chapter 7 (Tables 722.2.1.1, 722.2.2.1, 722.3.2) and are unchanged.
  - Slab rows now cite Table 722.2.2.1.

- **IBC/IFC Hazard v1.5.0 (2026-10-14).** Oxidizers now map to H-1/H-2/H-3, since Class 4 is H-1. Pyrophorics now map to H-1/H-2: detonable materials are H-1 and nondetonable are H-2.
  - Basis: IBC (2024) 307.3 and 307.4, verified on ICC Digital Codes free access (IBC2024V2.0 Ch. 3).
  - The explosives review note still stands.

- **Occupant Egress v1.3.0 (2026-10-15).** Rechecked against IBC 2024 on ICC Digital Codes free access (IBC2024V2.0 Ch. 10).
  - Table 1017.2, 1017.2.2 and Table 1004.5 are unchanged; their citations now read 2024.
  - Common path now follows Table 1006.2.1 by subgroup:
    - M and U: 75 ft.
    - H-1 to H-3: 25 ft. H-4, H-5, I and R-1: 75 ft. R-2 to R-4: 125 ft.
    - H, I and R are not permitted without sprinklers.
    - The nonsprinklered value uses the OL > 30 column.
  - Dead ends now follow 1020.5: I-1 is 50 ft sprinklered; I-2/I-3, I-4 and R-3/R-4 are 20 ft.
  - R is split into R-1, R-2 and R-3/R-4; a saved R project opens as R-1.
  - Not modeled: the one-exit maximum occupant load, the I-3 Condition 2–4 and I-2 Condition 2 dead-end exceptions, and the 1017.2.3 H-5 increase.
