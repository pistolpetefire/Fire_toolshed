MAQ & Control Area Calculator — Help

How the MAQ is set

  • Base MAQ from IFC Table 5003.1.1(1) (physical hazards) or 5003.1.1(2) (health hazards), for storage, use-closed and use-open.
  • Note d: +100% when the building is sprinklered throughout per 903.3.1.1. Note e: +100% when stored in approved storage cabinets, gas cabinets, exhausted enclosures or safety cans. When both apply they multiply (×4).
  • Note f: not limited when sprinklered (e.g. Class IIIB liquids, Class 1 oxidizers). Note g: allowed only in sprinklered buildings.
  • Per-story percentage and maximum control areas from Table 5003.8.3.2 (IBC Table 414.2.2), applied after all increases.
  • Note b: total use plus storage may not exceed the storage MAQ including increases.
  • Note h: when more than one Class I flammable liquid row is entered, IA + IB + IC is also checked against the combination MAQ.
  • The cabinet increase for a class is used only when every row of that class is checked as in cabinets.

Group H call

  • Health hazards (corrosive, toxic, highly toxic) above MAQ are always H-4 (IBC 307.6), never H-3.
  • Flammable / combustible liquids (I, II, IIIA) and Class 3 oxidizers: H-2 in open systems or closed systems above 15 psig (IBC 307.4), otherwise H-3 (IBC 307.5).
  • Unstable reactive Class 3: H-1 if detonable, else H-2. Explosives Division 1.3: H-1 unless IBC 307.3.1 conditions are met (H-2).
