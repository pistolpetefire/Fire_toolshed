User Guide

  • Select class and number of standpipes. Flow is 500 gpm for the first plus 250 gpm each additional, capped at 1,000 gpm (sprinklered) or 1,250 gpm (unsprinklered).
  • Residual at the top outlet: 100 psi (Class I/III) or 65 psi (Class II).
  • Add elevation and friction to get base demand. Flags PRDs and zones over pressure limits.
