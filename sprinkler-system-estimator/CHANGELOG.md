# Sprinkler System Estimator changelog

- **1.10.0-prelim.** Storage / ESFR mode compares NFPA and FM side by side. Sprinkler demand is number of heads × K × √P, then hose and duration. Built-in cells are only the figures named for this module (NFPA 13-2022 Table 23.3.1 and Table 20.15.2.6, FM Data Sheet 8-9 Tables 8 and 14, and blank fields for FM Data Sheet 3-26 Table 2 and section 2.3.1.14). An edition selector chooses NFPA 13-2022 or a user-entered edition. The FM revision is typed by the user. K-14 and K-22.4 are flagged as not permitted for the Class IV, 35 ft storage, 40 ft ceiling row. The criteria-assisted ESFR planning presets (K-25.2 at 60 psi and K-14.0 at 75 psi) are unchanged. Report logo options are unchanged (AI&P + Benham, Benham, Haskell, upload, from shared `shared/report-logo.js`).
- **1.6.2-prelim.** New "Submittal mode" checkbox next to Print (shared module `shared/submittal-mode.js`, default OFF, per printout, not saved). ON leaves the blank sign-off block (Prepared by / Reviewed by / AHJ discussion notes) out of the printout. Everything else on the printout is unchanged. OFF is identical to 1.6.1-prelim. This app has no "Items to confirm" list, confirm-with-AHJ tags or Criteria Status column, so only the sign-off block applies.
- **1.6.1-prelim.** Report logo list gains a built-in option **AI&P + Benham (a Haskell Company)** (AI&P Alberti Ozzo & Partners + Benham). It is added once in the shared `shared/report-logo.js` (source key `aip`, image `shared/logos/aip-benham.png`), so it shows in this tool's Report logo list and preview and in the printout header. The default logo (Benham) and a saved choice (`fireToolshed.reportLogo.v1`) are unchanged. No layout changes.
- Previous versions in the app before this changelog file was kept current: 1.7.0-prelim (highest ESFR 40 ft planning presets), 1.8.0-prelim (Hazen-Williams lead-in and riser), 1.9.0-prelim (jurisdiction, roof main, governing hazard).
