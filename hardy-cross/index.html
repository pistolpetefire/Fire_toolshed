User Guide

  • Enter two path head losses and flows. Sign convention: clockwise positive.
  • Correction: ΔQ = −Σh / (1.85 · Σ(h/Q)). Iterates until tolerance or max passes.
  • Fails if it does not converge. Use for a two-path split first; multi-loop can be extended.
