v0.1.0 · Dual Ceiling (Open / Grid)

User Guide

Upload a floor plan PDF and an FX criteria sheet (or define criteria manually). The app supports both open bay and reflected ceiling plan with drop ceiling grid from the start.

  • Ceiling Type — Choose Open Bay or Grid (RCP). Grid mode adds tile size and optional snap-to-center.
  • Floor Plan PDF — Architectural or reflected ceiling plan.
  • FX Criteria — Map hatchings/colors to hazard criteria (max area/head, max spacing, density). Upload sheet or enter manually.
  • Scale — Set or measure scale so dimensions are accurate.
  • Areas — Select regions (manual for now; auto-hatching detection planned) and assign criteria.
  • Generate — Places heads, dimensions them, and prepares marked-up output.

Compliant with NFPA 13 spacing rules for the assigned hazard. Always verify with the full standard and AHJ.
