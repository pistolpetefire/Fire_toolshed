Sprinkler Head Layout

v0.2.1 · Dual Ceiling + Polygons

User Guide

Upload a floor plan PDF. Draw coverage polygons, set spacing, then generate heads (open bay or grid).

  • Ceiling Type — Open Bay or Grid (RCP). Grid adds tile size field.
  • Load Plan — Upload floor plan PDF.
  • Scale — Feet represented by one canvas unit after render (tune until dimensions match the drawing).
  • Draw Polygon — Click to add vertices. Finish Polygon or double-click to close (min 3 points).
  • Max Spacing — Maximum distance between heads in feet for the layout.
  • Generate Layout — Places heads only inside the drawn polygons.
