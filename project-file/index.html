Cross-app checks

    Run record

    Run record for traceability only. Not a professional seal or certification.

    Verification against independent Python hand calcs

    The page loads built-in example files into a scratch hub and compares its values with verify_handcalc.py: RSET total, ASET − RSET margin, ASET/RSET ratio, the movement difference between Stair Merge and the RSET session, the section count, and that every section comes back unchanged after save and reload. Acceptance: within 1%, or exact for counts.

    User guide

    What each input is, what is typical, and why. The hub adds no engineering values of its own; acceptance criteria stay per project and AHJ.

    Workflow

    1. Work in each app as usual and export its file (ASET Screener, Stair Merge and Travel Distance: Export project JSON; RSET Tool: Save Session).
    2. Open the hub, name the project, and add the files. Use "Read ... saved in this browser" for Occupant Load and the atrium tools.
    3. Read the cross-app checks: project names, ASET vs RSET margin, and whether the RSET movement matches the Stair Merge handoff.
    4. Save the shared project file. Keep it with the project records.
    5. Later, add the shared file back to the hub, or open it directly in ASET Screener, Stair Merge or Travel Distance. Use Extract for the RSET Tool and the others.

    Reading the checks

    • Error (red): a file that cannot be read or is not a Fire Toolshed file.
    • Warning (amber): RSET above ASET, project names that differ, an RSET movement that differs from the Stair Merge handoff, or an RSET tenability limit that differs from the ASET result.
    • Note (gray): sections that are missing, so a check could not run.

    Common mistakes

    • Mixing files from different revisions or projects.
    • Updating an app but not re-adding its export, so the hub holds old values.
    • Reading browser data on a different computer, where it does not exist.
    • Treating the margin as an acceptance decision; the safety factor and criteria are per project and AHJ.

    Sources

    • Each section's method and sources are those of its app (see each app's User guide).
    • ASET vs RSET comparison: SFPE Engineering Guide to Performance-Based Fire Protection, and the SFPE Handbook human behavior and egress chapters (5th Ed.).
    • JSON Schema draft 2020-12 (json-schema.org) for the file format.
